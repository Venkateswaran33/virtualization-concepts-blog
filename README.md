# VirtualizationLab — Virtualization Concepts Blog

A responsive, static educational website covering:
- Hardware and software virtualization
- Server and network virtualization
- Type-1 and Type-2 hypervisors
- Containers vs. virtual machines
- Virtualization costs, benefits, and challenges

## Run locally
Open `index.html` in a browser. No build tools are required.

## Publish with GitHub Pages
1. Create a new **public** repository on GitHub.
2. Upload `index.html`, `styles.css`, and `script.js` (and this README).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will display the published website URL in the Pages section.

## Accessibility and design
The site uses a dark navy hero with white/cyan text, dark body text on light backgrounds, responsive layouts, keyboard-friendly links, and reduced-motion support.
